SAFFRON TABLE — RESTAURANT WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the saffron_table_restaurant folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.

PAGES
- index.html: Home
- about.html: Our Story
- services.html: Services
- gallery.html: Gallery (click images to enlarge)
- contact.html: Contact and reservation request form

TECH
HTML5, CSS3, JavaScript. Responsive layout, CSS gradients, reveal-on-scroll animation,
mobile navigation, image lightbox, and a reservation form that prepares an email.

IMPORTANT CUSTOMIZATION
- Replace the demo restaurant name, address, phone and email with the real details.
- The reservation form is front-end only. It opens the visitor's email app; it does not
  save bookings to a database. For real online booking, connect PHP/Node.js + a database.
- Photos are loaded from Unsplash, so an internet connection is needed to display them.
- Replace hello@saffrontable.example in contact.html and js/main.js with a real email.
